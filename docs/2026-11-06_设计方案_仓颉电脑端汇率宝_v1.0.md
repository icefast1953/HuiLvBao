# 仓颉电脑端汇率宝设计方案

日期：2026-11-06。目标：实现可在Windows本机运行的仓颉汇率工具，提供多币种换算、数据查询、缓存与显示设置。

## 目标与边界

- Windows 本机运行，浏览器提供界面；仓颉实现业务计算、本地 HTTP 服务、报价与历史数据、缓存、自选与设置。
- 独立工作目录，不修改原 Android 工程，不迁入原 Java 实现及其 Git 历史。
- 原项目数据目录可作为参考资源使用，保留来源说明；参考目录可见不等同所有货币都有有效报价。
- 不增加账号注册、交易、资产管理或真实支付；“YuEBao”为用户指定仓库名，产品仍为汇率工具。
- 自动更新仅在本地应用进程运行期间生效；电脑休眠、应用退出不保证后台更新。

## 功能与验收

| 需求 | 功能 | 验证 |
| --- | --- | --- |
| FR-01 | 任一自选币种作为输入源，多币种同时换算；最多18位整数、6位小数 | 100 CNY 固定样例；HALF_UP；JPY零小数；边界和非法输入 |
| FR-02 | 币种搜索、自选添加删除、去重、至少保留一个 | 持久化重开；删除源币种重设为首行与金额1 |
| FR-03 | 独立单位汇率列表、基准选择、报价日期及缓存状态 | 页面金额不影响单位1；缺失报价明确展示 |
| FR-04 | 7/30/90日历史曲线与真实日期列表，按货币对和范围缓存 | 升序去重、缺口/空/单点、切换查询及离线回退 |
| FR-05 | 手动更新、自动更新开关和1/6/12/24小时间隔 | 有效响应校验；失败保留缓存；无重复刷新；进程内定时 |
| FR-06 | 中文/英文、系统/无衬线/衬线字体、小/中/大字号 | 设置持久化、即时显示、输入源与原文保持 |

计算使用仓颉任意精度整数实现十进制定点运算，仅最终显示舍入，拒绝二进制浮点金额计算。缺失报价不以0或样例代替。提供明确标识的固定数据演示模式，真实模式不混入演示数据。

## 实现选择

这是实现者根据电脑运行要求作出的选择：仓颉官方2026-11-06构建1.3.0-alpha、匹配版本stdx、HTML/CSS/原生JavaScript，无Node业务后端。HTTP仅绑定127.0.0.1；页面和接口同源。金额不发送到外部报价服务。

代码按计算、JSON/HTTP适配、数据与持久化、路由及界面拆分。静态文件只通过固定白名单提供，修改请求检查本地来源，输入与错误均验证。缓存和个人设置不提交到GitHub。

外部数据源沿用Frankfurter公开参考汇率，展示数据日期与获取时间。历史按实际观测日期展示，保留周末与假日缺口。真实接口可用性与币种覆盖由实际调用验证，不承诺分钟级报价及全部参考币种可兑换。

## 已知原项目边界

原项目的完整参考币种报价覆盖仍有未验项；本次不沿用“全部覆盖”结论。电脑端不移植Android专用旋转、输入法或WorkManager机制，以浏览器状态保持与进程内定时替代。

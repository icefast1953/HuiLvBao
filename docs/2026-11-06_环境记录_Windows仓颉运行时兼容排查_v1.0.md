# Windows仓颉运行时兼容排查

2026-11-06。正式版1.2.0与LTS 1.0.5均已从官网下载并校验SHA-256；两者的工程工具和最小println程序在当前Windows上均以0xc0000005退出。Windows事件记录指向msvcrt.dll的wcslen。

官方仓库`Cangjie/cangjie_runtime`的`runtime/src/os/Windows/WinModuleManager.cpp`明确记录issue #920：新版Windows加载器结构变化使旧版模块枚举读取错误地址。上游改用公开Win32模块枚举接口。

采用官网链接所指官方nightly_build中2026-11-06构建`1.3.0-alpha.20261106001044`，校验该构建附带SHA-256后解压，匹配同日stdx。实际验证：`cjpm --version`返回1.3.0-alpha.09；最小程序打印CANGJIE_RUNTIME_OK并返回0。

因此本工程锁定该官方构建。此版本为预发布版，后续可在包含修复的稳定版上重新跑全部测试后迁移。没有修改系统DLL、系统安全配置或全局PATH。

金额模块先运行缺失`convertAmount`/`validAmount`的失败测试，再实现BigInt十进制定点运算；四项测试实际通过（固定样例、HALF_UP与JPY、最大精度、输入边界）。测试框架使用本机回环连接收集结果，需在允许本机连接的运行环境执行。

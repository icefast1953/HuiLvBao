# 币种参考数据来源

`currencies.json`保留既有Android汇率宝`app/src/main/assets/currencies-reference.json`的原始数据，作为本次重写的参考资源，不属于迁入Java代码。各条数据的`catalog_reference`、单位、状态和小数位保留。

该参考集合来自原项目核对的iMoney官网旧版资源；它不是当前商店版全集，也不代表全部条目都能从Frankfurter取得有效报价。网络数据缺失时明确显示无报价，不以目录存在替代真实兑换覆盖。

`identity-bindings.json`保留原项目已核对的同代码、法币、单位1绑定清单。联网只对该清单中的代码采用同名数据源身份；未核对的历史币种、贵金属、特殊单位保留在目录中并显示暂无有效报价。

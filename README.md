# 汇率宝 · Cangjie

以既有 Android 汇率宝的功能需求为参考，从空仓库重新实现的仓颉电脑本地版。此仓库由 AI 辅助开发；提交按实际完成顺序和实际时间记录。

## 计划功能

多币种精确换算、自选币种、单位汇率列表、真实历史走势、本地缓存、手动/进程内自动更新、中英文和显示设置。

仓颉负责业务及本地服务，浏览器负责界面。当前阶段：设计与开发环境验证，尚未完成可运行应用。

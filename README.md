# 汇率宝 · Cangjie

汇率宝是一款使用仓颉语言实现的电脑端汇率工具，支持多币种金额换算、单位汇率查询和历史走势查看。应用在本机运行，通过浏览器提供操作界面，设置与缓存保存在本地。

## 功能

- **多币种换算**：编辑任意币种的金额，其他自选币种同步换算。使用BigInt十进制定点计算，支持最多18位整数、6位小数，按币种精度采用HALF_UP舍入。
- **币种管理**：按代码或中英文名称搜索，添加、移除自选币种，防止重复添加并至少保留一种币种。
- **单位汇率**：选择基准币种，查看1单位基准货币对应的汇率及报价日期。
- **历史走势**：查询7、30、90日历史曲线和日期列表，按实际观测日期展示数据。
- **更新与缓存**：支持手动刷新、自动更新及1、6、12、24小时间隔；网络失败时保留已有有效缓存。
- **显示设置**：支持简体中文、英语、跟随系统，以及字体和字号设置。

## 环境要求

- Windows x64。
- 仓颉SDK：`1.3.0-alpha.20261106001044`，配套同版本stdx扩展库。
- 支持JavaScript模块的现代浏览器。
- Node.js仅在运行页面测试时需要。

在仓库根目录创建`local.env.ps1`，按安装位置配置：

````powershell
$env:CANGJIE_HOME = 'D:\tools\cangjie'
$env:STDX_HOME = 'D:\tools\stdx\windows_x86_64_cjnative'
````

`CANGJIE_HOME`应包含`envsetup.ps1`，`STDX_HOME`应包含`dynamic/stdx`。安装与配置方法见[使用说明](docs/2026-11-06_使用说明_电脑端运行与验证_v1.0.md)。

## 启动与停止

| 入口 | 用途 |
| --- | --- |
| `start.cmd` | 启动真实数据模式并打开浏览器 |
| `demo.cmd` | 启动固定样例演示模式 |
| `stop.cmd` | 停止应用，保留缓存和设置 |

访问地址：<http://127.0.0.1:18627>。

真实模式和演示模式分别使用`.local/live`与`.local/demo`。切换模式前先停止当前实例。

## 构建与测试

| 命令 | 用途 |
| --- | --- |
| `scripts/build.ps1` | 构建仓颉程序 |
| `scripts/test.ps1` | 运行21项仓颉测试 |
| `node --test tests/ui-model.test.mjs` | 运行5项页面状态测试 |
| `node tests/http-integration.mjs` | 对运行中的演示模式执行HTTP联调 |

HTTP联调会初始化演示模式所需的CNY、USD自选币种。真实接口探测需先载入`scripts/env.ps1`，再执行`target/release/bin/main.exe --probe`。

## 项目结构

- `src/`：仓颉计算、数据存储、网络请求和本地服务。
- `web/`：页面、样式与交互逻辑。
- `assets/`：币种目录、数据源绑定及演示数据。
- `scripts/`：环境配置、构建、测试和运行入口。
- `tests/`：页面状态测试与HTTP联调。
- `docs/`：设计、使用和验证说明。

## 数据说明

汇率来自Frankfurter公开每日参考数据，供金额估算使用。173项为参考币种目录，151项为数据源身份绑定清单；目录中可见的币种不一定都有有效报价。缺失或未核实的报价会明确标注。

自动更新只在应用进程运行期间生效，退出应用或电脑休眠后可能延后。演示数据与真实数据分开保存，页面会标识演示模式。金额在本机计算，外部请求只包含币种与日期等查询参数。
